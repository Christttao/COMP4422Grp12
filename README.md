# COMP4422 Group 12 — 3D Scene (M1–M3)
## How to Run
A local HTTP server is required (the `.obj` is fetched over HTTP, and the app uses ES modules).

```bash
cd COMP4422Grp12
node server.js
# open http://localhost:8000
```

OR

```bash
cd COMP4422Grp12
python -m http.server 8000
# open http://localhost:8000
```

## Controls
| Input | Action |
|-------|--------|
| Drag mouse | look around |
| W / S | move forward / back |
| A / D | strafe left / right |
| Q / E | move up / down |
| Arrow keys | turn / tilt |
| Mouse wheel | change field of view |
| Shift | move faster |
| 1 | Toggle Ambient lighting |
| 2 | Toggle Diffuse lighting |
| 3	| Toggle Specular highlight |
| L	| Pause / Resume light orbit |
| P	| Pause / Resume scene animation |
| R	| Reset light and toggles |
